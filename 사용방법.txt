SimplePDF 1.0.4

실행: release_rust\SimplePDF\SimplePDF.exe
Python이나 Adobe Acrobat을 설치하거나 로그인할 필요가 없습니다.
이 폴더의 바로가기로도 실행할 수 있습니다.
프로그램을 옮길 때는 SimplePDF.exe와 pdfium.dll을 함께 옮기세요.

PDF 편집
1. PDF 열기 또는 PDF 파일을 프로그램 창으로 끌어 놓습니다.
2. 상단 선택 상자를 '문구 수정'으로 바꾸고 텍스트 한 줄을 클릭합니다.
   팝업 없이 클릭한 행에 커서가 나타납니다. 입력 내용은 화면에 바로 반영됩니다.
   편집 중에도 PDF의 원본 글꼴·굵기·기울임체를 유지합니다.
   한 줄에 여러 글꼴이 섞여 있어도 각각 유지합니다.
   오른쪽 텍스트 속성에서 글꼴 이름을 눌러 한글 또는 영문으로 검색합니다. 방향키와 Enter로 선택하거나 결과를 클릭합니다. 크기와 색상도 여기서 바꿀 수 있습니다.
   Enter 또는 다른 행 클릭으로 확정하고, Esc로 입력을 취소합니다.
   문구를 비우고 확정하면 선택한 줄의 텍스트를 삭제합니다.
3. '텍스트 추가'에서 영역을 드래그하고 문서 위에 입력합니다. Enter는 줄 바꿈, Ctrl+Enter는 완료입니다.
4. '이미지 추가'에서 새 사진을 넣을 영역을 드래그한 뒤 파일을 선택합니다.
5. '이미지 편집'에서 윤곽선이 표시된 기존 사진을 클릭하고 교체할 파일을 선택합니다. 새 사진은 같은 위치와 크기에 들어가며, 비율이 다르면 가운데를 기준으로 잘라 맞춥니다.
   사진 위에 마우스를 올리면 PDF에 저장된 이미지의 가로 × 세로 픽셀 수가 한 줄로 표시됩니다.
   보기 또는 이미지 편집에서 사진을 우클릭하고 ‘이미지 내보내기…’를 선택하면 원본 크기의 PNG를 PC에 저장합니다.
6. 문구 입력 중 Ctrl+Z와 Ctrl+Y는 현재 문구에서 입력한 내용을 되돌리거나 다시 실행합니다. 편집을 확정한 뒤에는 문서 변경을 되돌리거나 다시 실행합니다.
7. '저장'으로 편집 결과를 새 PDF에 저장합니다.

화면·조작
- 상단 40px 한 줄과 왼쪽 책갈피를 기본으로 표시합니다. 하단 상태바는 없습니다.
- PDF를 열면 페이지 맞춤(100%)으로 표시합니다.
- F11: 상단 줄도 숨기는 전체 화면. Esc: 복귀.
- 메뉴 또는 문서 우클릭: 편집·페이지·변환 기능.
- Ctrl+O / S: 열기 / 저장.
- 상단 돋보기 또는 Ctrl+F: 문서 전체 검색. 검색창은 문서 위에 겹쳐 표시됩니다.
- '대소문자 구분'은 기본으로 꺼져 있습니다. e23으로 검색하면 e23과 E23을 찾습니다. 영문과 숫자를 조합한 코드는 전체가 일치해야 합니다. 숫자만 입력하면 부분 검색하므로 23으로 -23도 찾을 수 있습니다.
- 검색어를 입력한 뒤 Enter를 누를 때마다 다음 결과로, Shift+Enter를 누를 때마다 이전 결과로 이동합니다. F3와 Shift+F3로도 이동할 수 있습니다. Esc를 누르면 검색창이 닫힙니다.
- 검색 결과는 강조되며 마지막 결과 다음에는 첫 결과로 돌아갑니다.
- PDF 본문 목차의 내부 링크를 클릭하면 연결된 페이지와 위치로 이동합니다.
- 링크가 없는 텍스트 목차도 목차 제목과 페이지 번호를 인식하면 클릭으로 이동합니다.
- Ctrl+Shift+P: 오른쪽 텍스트 속성 패널을 펼치거나 접습니다.
- V / E / T / I: 보기 / 문구 수정 / 텍스트 추가 / 이미지 편집. Shift+I: 이미지 추가.
- Ctrl+PageUp / PageDown: 이전 / 다음 페이지. Ctrl+L: 페이지 번호 입력.
- Ctrl+휠: 화면 중앙을 기준으로 한 칸당 약 30% 확대·축소합니다.
- 페이지 맞춤이 100%입니다. 숫자 배율도 페이지 맞춤을 기준으로 표시합니다.
- Ctrl+0 / 9 / 1: 너비 / 페이지 맞춤 / 100%(페이지 맞춤).
- 상단 두 페이지 아이콘 또는 Ctrl+2: 한 페이지 / 두 페이지 보기 전환.
- 두 페이지 보기에서는 클릭한 쪽을 편집하고, 이전·다음 및 휠은 두 쪽씩 이동합니다.
- 페이지 전체가 보일 때는 휠 한 칸에 한 페이지(두 페이지 보기에서는 두 쪽)씩 즉시 넘깁니다. 빠르게 돌리면 돌린 칸 수만큼 연속해서 넘어갑니다.
- 확대 후에도 일반 휠로 스크롤합니다. 페이지 끝에서는 다음/이전 페이지로 이어집니다.
- 보기 모드에서는 배율에 관계없이 글자 위에서 왼쪽 버튼을 누르고 드래그해 텍스트를 선택합니다. Ctrl+C 또는 우클릭의 '텍스트 복사'로 복사합니다. 확대 화면은 마우스 가운데 버튼으로 끌어 이동할 수 있습니다.
- PDF 여러 개를 선택하거나 창에 끌어 놓으면 상단 한 줄에 문서별 탭이 표시됩니다. 탐색기에서 추가로 여는 PDF도 같은 창에 열립니다.
- 탭을 클릭하거나 Ctrl+Tab / Ctrl+Shift+Tab으로 전환합니다. 탭의 × 또는 Ctrl+W로 닫습니다. 자리가 부족하면 ···에서 전체 탭을 선택합니다.
- 상단 페이지 맞춤 아이콘 버튼: 문서 한 페이지를 화면에 맞춥니다.
- 상단 책갈피 아이콘 버튼 또는 Ctrl+B: 왼쪽 책갈피 패널을 펼치거나 접습니다.
- 책갈피를 클릭하면 해당 위치로 이동합니다. 다음 책갈피가 시작될 때까지 현재 절이 강조됩니다.
- 책갈피의 + / −로 하위 항목을 펼치거나 접습니다. 패널 오른쪽 경계를 드래그하면 창 크기에 따라 최대 960픽셀까지 넓힐 수 있습니다.
- Ctrl+D 또는 패널의 +: 현재 페이지를 책갈피로 추가합니다.
- 책갈피 우클릭: 하위 항목 추가, 이름 바꾸기, 삭제. 변경 후 PDF를 저장하세요.
- 우측 반투명 스크롤바: PDF 위에 겹쳐 표시되며 문서 폭을 줄이지 않습니다.
- 상단 빈 영역 드래그: 창 이동. 화면 위쪽/좌우 끝으로 끌어 최대화/반쪽 배치.
- 상단 더블클릭: 최대화·복원.

페이지 메뉴
- PDF 추가·병합, 페이지 범위 추출, 회전, 순서 변경, 삭제
- 페이지 범위 예: 1,3-5 / 빈 칸은 전체

변환 메뉴
- PDF → 편집 가능한 Word (.docx): Adobe·Microsoft 계정 없이 처리
- 이미지가 있는 페이지는 사진의 잘림·투명도·회전·겹침을 유지합니다.
  일반 가로 글자는 원래 위치의 Word 텍스트 상자로 편집할 수 있습니다.
  회전·가려짐·미설치 글꼴 등 재배치가 어려운 부분은 원본 모양의 이미지로 유지합니다.
  이미지가 없는 일반 문서는 문단과 표 형태로 변환합니다.
- PDF의 표 → Excel (.xlsx): 인식한 표마다 시트를 생성
- PDF → PNG / JPG: 페이지마다 이미지 생성
- 이미지 → PDF: 선택한 이미지들을 하나의 PDF로 결합
- 변환 메뉴에서 'Word · PowerPoint · Excel → PDF'를 선택하고 원본 문서와 PDF 저장 위치를 지정합니다. PC에 해당 Microsoft Office 앱이 설치·인증되어 있어야 합니다.
- 설치 후에는 탐색기에서도 문서를 우클릭해 'PDF로 변환'을 선택할 수 있습니다. Windows 11에서는 탐색기 확장을 설치하면 첫 우클릭 메뉴에서 바로 선택할 수 있습니다. PDF는 원본 폴더에 저장되며, 같은 이름이 있으면 '문서 (2).pdf'부터 번호가 붙습니다.

지원 범위
- 파일은 PC 안에서 처리하며 서버에 업로드하지 않습니다.
- 스캔 이미지의 글자 인식(OCR)은 포함되지 않습니다.
- 텍스트를 한 줄 단위로 수정합니다. 기존 글꼴·문단 전체를 재배치하는 워드프로세서는 아닙니다.
- 복잡한 PDF를 Word로 변환하면 서식이나 줄 배치가 달라질 수 있습니다.
- Excel 변환은 표 인식 기능이며 스캔 이미지나 모든 문서 배치를 표로 바꾸지는 않습니다.
- 암호가 걸린 PDF는 암호가 필요합니다. 편집 권한이 제한된 PDF는 수정할 수 없습니다.
- 전자서명된 문서를 수정하면 서명이 무효화될 수 있으므로 원본을 보관하세요.

소스 코드: Cargo.toml, src, build.rs
개발 빌드: Windows x64에서 Rust와 C/C++ 링커를 준비하고 cargo build --release --locked를 실행합니다.
검증: SimplePDF.exe --self-test <결과 폴더>
설치 파일 빌드: build.ps1 -Package (Inno Setup 필요)
